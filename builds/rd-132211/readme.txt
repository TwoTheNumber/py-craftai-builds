Welcome to (what i call) "PyCraft AI"
mineCRAFT written in PYthon and code generated by AI (hence the name)
this only took 28 prompts in google gemini and was made in a span of a few hours.


DEPENDENCIES

python (i'd use 3.13)
ursina (i installed 8.3.0 but it prob works with older)

SIZE

this is pretty well optimized (because its just a script and a .png)
only being 88kb (excluding python and ursina)

this tries to replicate old minecraft (for this build its alpha rd-132211)
and somehow runs BETTER than the real thing on my pc
the save system is now very optimized using 6 bytes for coords and 1 for block state
it also only remembers modified blocks (before the saves were abour 55mb and now they're less than 1kb for small builds)

CONTROLS 
W, A, S, D to move
space to jump
left click to place
right click to destroy (i forget this often)

KNOWN GLITCHES

if you turn to the right while in front of a block and w is held you start moving into it
if you mine blocks while standing inbetween 2 you clip into one,
this is solved by walking forward away from the block or by building so you arent not next to a block.
